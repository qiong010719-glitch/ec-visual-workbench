# 多平台工作台验证记录

验证日期：2026-11-19。范围是本次多平台改造的独立工作副本，整合基线为 `629bc00`。原工作台与另一个对话的实时开发目录未被替换，4185 服务未重启。

## 实现与边界

- 六个入口使用公共商品、平台版本、连接设置、任务记录和可恢复的设计/上架状态。
- Amazon 使用原有主副图、普通/高级 A+ 方案和尺寸；Temu 沿用原图片处理及店小秘执行链路。
- 完整成品直接进入上架中心；生成未完成、失败或缺图的版本不能提前交接。已保存的旧图片草稿仍可恢复。
- 上架平台来自已绑定店铺。Amazon 可制作、核对、导出，尚无 Amazon 自动发布执行器。
- 极鲸云 / GeekBI 的界面品牌展示改为“选品数据服务”。配置键、外部控制台地址、API 请求和用户保存的标题/文件夹不因此改变；旧选品与设置书签进入同一新版外壳。
