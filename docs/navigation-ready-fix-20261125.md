# 店小秘核对页面跳转修复

2026-11-25。适用当前 4196 跨境工作台。

## 已确认的原因

点击“核对认领与资料”后，执行器打开 SHEIN 采集箱。真实只读复现捕获到 Chrome 在导航提交期间返回 `url: ""`：目标仍存在、类型为 page、由当前任务创建、浏览器用户一致。此前范围检查立即返回 `CHROME_EXISTING_TARGET_DENIED`；执行器的 finally 随后关闭自建标签页，造成页面一闪消失。

## 修复

- 为当前连接中工作台自建页面的创建和允许的导航记录最多 10 秒的就绪期限。网址暂时为空时仅轮询 Chrome 目标元数据，不向该页面执行读取、点击或其他命令。网址恢复为允许范围后继续。
- 未知页面、用户原有页面的空网址、目标关闭、跨用户和跳转到非业务网址仍停止；持续空网址返回明确的 `CHROME_EXISTING_NAVIGATION_TIMEOUT`，不重发导航或业务操作。
- SHEIN/TikTok 必填补全执行器在异常或待核对结果时保留页面，释放自动化连接；成功完成的临时页面继续正常清理。
- 运行脚本与打包脚本保持一致。工作台与启动器版本同步为 `crossborder-navigation-ready-20261125-2`。

- 增加平台导航失败和返回待核对结果时保留标签页、释放页面会话的回归覆盖。
