# 设计参考库

本地工作台新增“设计参考库”。图片先采集或导入，再下载原始文件，最后发送给支持图片输入的视觉模型分析。三个阶段分别记录状态，采集成功不等于已经学习。

## 当前数据与使用方法

1. 打开工作台右上角“设计参考库”。
2. 点击“查看图片与设计分析”，可以逐图查看构图、镜头、光影、配色、文字层级和可迁移方法。
3. 选中参考后点击“用于当前商品策划”，再重新构思。每次最多采用 3 套匹配参考；未选时自动匹配类目，相关性接近时优先选择不同品牌。
4. 方案生成后仍可编辑。生图时每个槽位只取得全局要求与本槽位段落。竞品图片不会成为新商品的身份参考；当前商品资料决定参数、功效、品牌与结构。

用户提供的 Charmast 全店归档包括商品/变体图、A+、品牌故事和装修页面图片。按 SHA-256 对文件去重，同时保存每张图的所有使用位置。分析缓存以文件哈希复用，颜色不同但文件不同的图片仍分别分析。

“完整覆盖”只对应给定归档的图片清单。装修图片的所属页面可以查到；归档没有完整 DOM、导航交互与响应式布局，不能由图片清单推断整页布局已一比一复原。装修图生成功能按用户要求留待之后实现。

## 配置

- Apify：本机 `.env.apify` 中的 `APIFY_API_TOKEN`。密钥只在服务器端使用，通过 Authorization 请求头发送；不进入请求 URL、前端、导出记录或源码包。
- 视觉分析：`VISION_BASE_URL`、`VISION_API_KEY`、`VISION_MODEL`；也支持已配置的 `PLANNER_*` 或现有通用 `SUANZHOU_API_KEY`。默认算舟视觉模型为 `gpt-5.4-mini`，此次已实际验证图片输入。
- 生图：仍只用 `SUANZHOU_IMAGE_API_KEY`。本次学习工作没有新增生图调用。
- 构思：未配置 `PLANNER_*` 时使用参考库辅助的本地规则，不应显示成“模型构思”。视觉分析已用模型，不代表构思也自动切到文本模型。

## Amazon 首轮抽样口径

站点是美国站，首个类目为 [Cell Phone Portable Power Banks](https://www.amazon.com/gp/bestsellers/wireless/7073960011)。采集使用 [Amazon Bestsellers Scraper](https://apify.com/junglee/amazon-bestsellers) 与 [Amazon Product Scraper](https://apify.com/junglee/amazon-crawler)。

先观察类目榜单，再读取商品详情验证品牌、图片和变体。品牌得分是同一类目榜单中不同款式的 `1 / 排名` 之和；选择得分最高的 5 个品牌，每个品牌优先取排名最好的 5 个不同款式。这是当前样本的品牌抽样规则，不是官方品牌榜或精确销量。

补充品牌搜索只用于发现商品。只有详情返回同一类目的 BSR 才能进入补充样本，搜索结果顺序不作为销量证据。记录榜单与详情两类排名来源、原始 ASIN、重定向后的 ASIN、采集时间、Actor 运行 ID 和数据集 ID。颜色变体以明确父 ASIN 或变体 ASIN 集合去重。

首轮已观察到上游返回重复分页记录：100 条原始数据只有 80 个独立商品，排名覆盖 1–80。该缺口不能用“API 成功”掩盖，运行保持 `partial`。具体品牌数量、费用与链接见本批采集报告。

费用上限通过 Apify `maxTotalChargeUsd` 传入每个运行。常规采集将本批上限分配给榜单与详情两个阶段。首轮补采只在前两阶段结束后，从已确认剩余额度中分配。远端提交结果不明时不自动重发；服务重启后只恢复已知运行的状态。Apify 费用与视觉分析费用分开。

## 后端接口

| 接口 | 用途 |
|---|---|
| `GET /api/research/status` | 配置是否就绪、图片下载与分析统计 |
| `GET /api/research/products` | 资料组列表 |
| `GET /api/research/products/:id` | 逐图来源与分析 |
| `GET /api/research/design-patterns` | 按角色整理的设计特征与证据 |
| `GET /api/research/jobs` | 采集/分析任务与缺口 |
| `GET /api/research/export` | 导出参考库，不含密钥 |
| `POST /api/research/import` | 导入商品 JSON 数组 |
| `POST /api/research/import-folder` | 导入本机单商品图片目录 |
| `POST /api/research/jobs` | 创建采集、下载或分析任务 |
| `POST /api/research/resume` | 恢复同步已有运行 |

变更接口沿用本地服务的会话令牌和同源检查。研究任务保存到独立资料文件，商品草稿与已生成结果继续保留。

## 验证边界

自动测试覆盖来源规范化、排名证据与变体去重、预算参数、提交结果不明、下载刷新、真实图片输入、分析覆盖检查、缓存复用、参考到策划的传递和逐槽位提示词。浏览器验收验证配置状态、选择保存、重新打开和逐图分析查看，使用临时测试资料，不产生服务费用。

真实素材学习有模型分析和人工抽样核对，未对全部图片进行第二遍人工复核。完成分析不证明商品宣传真实，也不证明新图转化率提高；后续实际生图需要单独验证商品一致性、文字质量和视觉变化。
