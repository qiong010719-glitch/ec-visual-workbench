## 原因

只读检查认领弹窗发现：SHEIN 分组中存在“[SHEIN店铺]”，控件未停用，但 checkbox 没有 value 属性，原生 value 为 `on`。读取器正确地没有把 `on` 当作真实 ID，后续匹配却要求空 ID 等于用户手填 ID，误报“目标平台店铺不存在、重名或已停用”。证据保存在 `outputs/shein-store-groups-20261125.json`、`outputs/shein-store-shein-label-20261125.json`、`outputs/shein-store-shein-control-20261125.json`。

## 行为

- 在已核对的店小秘账号和认领页面中读取完整平台、店名、控件 ID、停用状态；真实 ID 存在时仍严格校验。
- 仅对已验证不提供 ID 的 SHEIN 控件，允许按平台和唯一完整店名匹配。重名、停用、真实 ID 冲突分别报错。Temu 的 ID 校验行为不变。
- 提交意图包含当次店铺列表及账号、页面证据。后台重新核对；缺少证据、跨账号或与所选目的地不一致均不允许提交。
- 写入意图后再次读取弹窗，确认选中店铺、ID、商品集合和跳过重复设置没有变化；保留原有不明提交结果禁止重放机制。
- 旧任务保存的手填 ID 和站点不修改，不需要清空设置或重建任务。服务重启后仍先执行“只核对结果”。
- 设置页面说明 ID 为高级选填，不清楚可以留空；没有新增未经验证的店铺同步接口，也不将手填 ID 伪装为页面观察值。
