## 最终行为

- 删除文字拖动钉、原字位置标记、位置预设、旧/新位置框和待移动原文提示。
- 删除移字识别、蒙版生成、结果定位检查及仅供该流程使用的图片处理依赖；保留普通局部编辑、重绘和下载。
- 旧存档中的文字位置不再影响重绘。旧页面发送 `text_move:true` 返回 HTTP 410，在排队、记账和图片服务调用之前停止；旧移字任务不能继续恢复下载。
- 第一张主图的背景和文案按构思、整套风格及逐张要求安排。新规则构思、文本模型指令、极速首个分镜和最终逐图提示词均移除强制白底要求。

- 自定义宽高、SKU 图参考、整套风格保持可用。“一张图……”要求仍优先分配给卖点图，避免仅取消背景限制就改变其他分配行为。
