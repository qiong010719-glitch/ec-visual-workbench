# 跨类目场景广告风格接入

用户已查看 `reference/style-study-20261101/index.html` 并明确要求“多学习这种风格的图片，然后运用到我们的网站里面”。本次以该页及 `style-brief.json` 为目标，不重复请求对已说明方向的批准。

目标是完整场景、真实动作、材质特写、清晰图文与统一品牌风格的整套商品图。扩充真实亚马逊样本，逐图视觉分析后用于检索；第一张白底主图与无文字的THD规则继续单独处理。新建构思默认采用场景广告风格，网页提供原有风格选项。历史生成结果和用户产品资料保留。

采用现有参考库与Node服务，新增独立风格/分镜模块。选择理由：继续使用现有已分析图像及逐槽位生图流程；只增加泛泛的风格词不能解决系列一致性，而直接复制竞品图形或商品内容会损害当前商品一致性。

必须把整套颜色、字体、光照、信息密度与每张的卖点、镜头、动作分开定义。跨类目借鉴只能移植设计方法，不能移植商品结构、品牌、参数或功效。用户手动选择参考优先。参考图不能成为当前产品身份参考。

修复数字分隔符导致25,000和20,000拆断的问题。两种设计模式严格分开：快速设计以信息表达与清楚演示为主，信息密度和场景倾向属于快速模式控制项；大师模式以摄影、光影、材质和叙事为主，独立决定精简的文案层级，不套用快速模式的密度或场景控制值。两种模式分别吸收参考风格，不能合并。原有单图编辑及手机重排不应被新风格悄悄覆盖。

分析使用已配置视觉模型；生图如需验证只使用专用图片密钥。采集使用浏览器，不新增Apify任务。样本覆盖与分析失败如实记录，不把采集等同于学习。

实现由当前会话自主完成；图片补充为独立并行子任务。目录不是Git仓库，使用本轮before快照保障可回溯，不初始化Git、不移动现有运行目录。
