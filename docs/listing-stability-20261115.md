# 上架稳定性修复（2026-11-15）

交付版本：`1.0.2-stability.1`。执行器标记：`listing-stability-20261115`。

## 修复范围

- 编辑描述、下拉选项和菜单在同一次页面执行中检查唯一性、可见性、禁用状态和遮挡，再点击一次。隐藏但占位的按钮不再提前通过等待。悬停最多恢复三次；已经点击成功的动作不会因结果迟到而重复点击。
- 详情清空、图片选择、导入、描述写回、保存回执等等待点带具体中文名称和等待时长。页面导航校验新的 loader 和目标路径，仅在只读检查遇到文档切换时继续等待。
- 一个执行批次复用编辑页和后台核验页。已保存商品、母稿和待发布列表的核验在后台页完成；不再把编辑页反复导航到核验页面。完成后回收程序创建的页面，失败时保留已填写的编辑页。
- 用户点击继续时，只回收带有该次执行标记、仍停留在对应未保存副本的旧失败页。已保存、已跳转或身份不符的页面保留并停止，不猜测保存是否成功。升级前没有执行标记的旧失败页不会自动关闭。
- 页面清理尚未结束时禁用继续按钮；重新启动时解除失效的清理标记。已核验商品、保存结果不明、发布结果不明仍沿用现有防重复规则。
- 新版桌面入口检查后台执行器版本，避免复用旧后台后仍运行旧逻辑。

## 诊断文件

每条商品的执行目录保留 `error.json`、`failure.png`，并为每次失败额外保存带时间戳的文件。错误包含货号、阶段、等待条件、等待时长、页面路径、相关控件数量及弹窗按钮；不采集密码、Cookie 或完整表单值。

原始两次故障的失败现场尚未取得。本次修复的是已确认的等待判断缺口、页面管理问题和定位信息缺失，不宣称已复现截图中第二次超时的确切触发点。

## 验证范围

隔离浏览器模拟覆盖隐藏/禁用/被遮挡按钮、首次悬停丢失、编辑器延迟、嵌套菜单、旧文档读取、标签复用与失败页身份校验。完整执行器测试在拦截全部网络的模拟店小秘页面中处理三件商品，验证图片写入、一次保存、回读、母稿不变、SKU 唯一和页面回收。

批次测试覆盖第二件失败后跳过第一件继续、执行中的重复点击、清理期间继续按钮锁定、重启恢复，以及保存或发布结果不明时禁止再次提交。

验证没有运行真实店铺上架、正式发布或付费图片生成。真实店铺表现仍需使用新版小批量验证。

## 使用新版

关闭旧工作台后运行 `dist/listing-stability-20261115/Temu-Workbench-1.0.2-stability.1-win-x64.exe`。同一 Windows 用户下的正式桌面模式沿用原用户数据目录；程序包不携带密钥、店铺配置或任务素材。

如果提示旧服务仍在运行，应关闭旧工作台或对应旧服务，再启动新版；不要同时开启两个版本处理同一批商品。需要保留现有任务数据，无需重新导入或重新生图。
