# 本地商品裂变工作台 V1

本版面向 Temu 半托管。商家在本机配置自己的模型、浏览器、店铺和母稿，然后导入多产品素材，生成多套图片及中英文商品标题，最后按所选店铺的母稿创建店小秘待发布草稿。

当前阶段先完成[本地业务稳定性验收](local-business-acceptance.md)，会员和公开收费暂缓。内部测试包与已通过/待完成的检查以该验收记录为准。

## 多 ERP 连接（2026-11-06）

“连接设置 → ERP 连接”现在可选择店小秘或妙手 ERP。每个连接分别保存 ERP 类型、浏览器和账号显示名；旧配置仍按店小秘处理。妙手使用官方入口 `https://erp.91miaoshou.com/`，支持保存连接、打开登录页面和检测指定浏览器中是否存在妙手页面。

妙手目前处于连接准备阶段，尚未验证账号登录、商品字段、母稿、保存及发布回读。看到妙手标签页不能算登录验证成功；当前不能把店铺绑定到妙手执行器，也不会自动套用店小秘脚本。下一步需要确定目标电商平台与经营模式，并使用已登录的妙手店铺页面完成实际适配。

多平台沿用“商品素材 → 平台字段与规则 → ERP 操作 → 店铺结果核验”的流程。平台与 ERP 是独立维度；新增一个 ERP 不会自动启用它支持的全部电商平台。每个 ERP 与平台组合需要单独验证。

## 启动

- 当前开发机：双击项目外层的 `启动本地工作台.cmd`，保留当前两家测试店及历史记录。
- 新电脑内部验收：运行 `dist/stability-20261111/Temu-Workbench-1.0.1-test.2-win-x64.exe`。无需另装 Node.js、Python 或 Excel；首次启动配置为空。当前是内部测试版，尚未完成对外使用验收。
- 开发期间网页入口：`http://127.0.0.1:4185/temu/listings`。桌面窗口与网页使用同一本机服务，日常商家不需要 Codex。
- 分发版的数据保存在当前 Windows 用户的应用数据目录；素材原件不会被改写。关闭窗口前需等当前任务结束或暂停。

## 首次连接

1. 打开“连接设置”。默认模型服务为 `https://api.suanzhou.vip/v1`，构思及标题模型为 `gpt-6.1-sol`，使用 Responses。图片模型可选 GPT Image 2 / GPT Image 2.5 Sunburst。
2. 填入商家自己的图片、文本密钥。未填写密钥时不能实际生图或生成标题。密钥使用 Windows 当前账户加密保存；不导出到 Excel、日志或安装包。
3. 添加比特窗口的本地 API 地址、窗口 ID、序号，打开该窗口并登录店小秘，点击“检查连接”。一个店小秘账号管理多家店时，可以共用这个浏览器连接。
4. 在店小秘保存完整商品母稿。在工作台点击“＋ 新增店铺”，先填写新店铺名称、站点及关联账号，再点击“下一步：添加该店铺的母稿”。填写母稿名称和编辑链接，点击“读取并校验母稿”，确认实际店铺、站点、类目与运费信息，再“保存新店铺”。上方“已添加的店铺”独立保留；修改已有店铺须点击对应的“编辑”。不再需要“存为模板”或选择模板名称。链接中的完整商品 ID 是唯一来源；旧模板名称只保留为历史资料，不参与选择。

旧配置及历史任务保留，未经新流程校验的显示“待校验”。校验会按 ID 打开店小秘“引用现有内容创建新品”的未保存副本，逐项比较字段；ERP 在引用时清空的库存会从母稿补回。店铺、站点或登录账号不符，缺库存或运费，以及当前不支持的规格结构都会明确拦截。校验不保存或发布 ERP 商品。

修改母稿后在店小秘保存商品，返回工作台重新读取即可。刷新页面或重开软件会恢复尚未保存的输入；配置版本变化则不恢复旧表单。开始构思或生图前会重新校验所选母稿，失败时不调用模型。

对“海报和印刷品”母稿，还会读取 SKU 预览图原文件，检查是否为宽高至少 800 像素的方图、且不超过 2 MB。错误提示会指出实际尺寸；请在店小秘“变种信息”中修正 SKU 图并保存，再重新校验。此规则未推广到尚未验证的其他类目。

保存店铺成功后，上架页会自动读取最新店铺和母稿列表；返回窗口、恢复页面以及停留在页面期间也会检查更新，无须重启软件。列表更新保留当前批次选择、商品输入和图片顺序，不会自动改投新店。填写或校验母稿尚不算保存店铺，保存按钮旁会明确显示保存成功或失败；未保存的店铺不会进入上架列表。

5. 当前执行器适用单 SKU、风格单变种、颜色为空、单仓库母稿。其他规格结构尚未通过实际验证；执行器会停止而非猜填。母稿里的价格、库存、仓库、运费模板须按真实商品维护。

## 原始商品素材 → 裂变

```text
原始商品/
  CANVAS-A/
    01.png
    02.jpg
    商品资料.txt
  CANVAS-B/
    01.png
    商品资料.txt
```

单个产品可直接选择放图片的文件夹（例如 `油画/产品`）；多个产品选择各产品子文件夹的上一级目录（例如 `油画`）。每个产品 1—8 张参考原图，支持 PNG、JPG、WebP、AVIF。在文本中写已确认的材质、尺寸、规格、包装内容、卖点；也可放一份 Excel，使用“货号、标题、商品资料”列。多产品时货号需与子文件夹同名；直接选择单产品文件夹时，表格仅填写该产品的一行资料。

结果可保存到独立的目录，例如 `油画/裂变`。读取素材时会跳过所选结果目录、已标记的工作台结果目录以及不含原图和商品资料的目录，并显示跳过清单。表格明确指定或带有商品资料但缺少原图的产品仍会报错。当前目录和子目录同时放有产品原图时，请按产品整理到同一层级后读取。

在“店铺上架”中选择“原图裂变并上架”，选择店铺、每套主图张数（1—10）、比例、设计方式，读取文件夹。左侧“本批使用母稿”可提前选择，并应用到本批全部商品；单个产品仍可分别选择，使用不同母稿时左侧会提示“多份母稿”。母稿名称和查看链接随实际选择更新，刷新会保留选择；已有执行记录的批次锁定母稿。左侧“＋ 新增店铺”直接进入新店信息步骤。分别确认每个产品的名称、真实资料、对应母稿和裂变套数。每个产品最多 20 套，单批最多 20 个产品/100 条商品；这是当前程序限制，不是 100 家店的并发性能承诺。

点击“保存本批商品”→“构思图片并生成标题”。查看不同人群、卖点及风格方向，核对标题后点击“生成本批图片”。图片和标题均按产品、套图编号关联；每套的商品标题与图片上印刷的短文案分开生成。

“真实商品资料”提供产品事实和做图备注。标题模型同时读取本批最多三张原始商品图，识别明确可见的主题、主体、图案和颜色，然后结合平台与店铺国家重写上架标题。主标题使用本站语言，例如加拿大英语、日本日语、德国德语、法国法语；未知国家会提示明确站点，不默认英文。界面左侧为“中文标题（核对用）”，右侧为店小秘所需英文标题；“查看 / 修改实际提交标题”中保留本站语言版本。中文编辑不会自动改写上架字段。加拿大实际提交的两字段均为英语。新生成标题同时提供中文；旧批次可点“补全中文标题”，只补中文核对版本，保留原有英文、图片、结果文件和执行回执。图片不作为尺寸、材质、手绘、配件或性能的证明，不复制做图方向和泛化卖点。

已有批次可点击“按店铺语言重新撰写标题”，只重写标题，不重做图片；新标题写入新的商品.xlsx，旧文件包和旧标题历史保留。若已有执行清单，仅同步尚未执行的条目；已经保存的店小秘商品及回执保留，其标题需要另行更新，不会自动重复创建商品。导出表格的“标题”列对应本站语言主标题，“英文标题”对应独立英文版本。

构思完成后，工作台统一检查跨套画面标题。发现重复时，自动使用已配置的文本模型进行一次局部改写，只更新冲突标题；重新检查通过才显示“方案与标题已就绪”。已提交图片的方案、用户明确指定的共用文案、其他分镜和商品资料保持原样。文本服务失败或改写后仍重复时，保留全部原方案，直接显示套数、图片位置和重复句；可点击“修正文案并检查方案”，或进入套图页重试修正、手动编辑。刷新和重启不会自动重复提交修正请求；图片生成仍需单独点击。

完成后点击“核对商品与图片”，在当前页面继续核对并保存到店小秘，也可导出文件夹与 Excel。导出表头为 **货号、标题、英文标题、中文核对标题**，每条商品的货号与对应图片子文件夹一致；工作台分配批次后缀以避免不同批次货号相撞。

顶部统一为“单品设计 / 店铺上架 / 连接设置”。店铺、平台、浏览器、文件夹及历史任务各保留一个入口；同一批的裂变、图片核对和执行进度合并在同一条历史任务中，已有独立执行记录也可继续打开。原 `/app` 地址自动进入“店铺上架”。

## 已有图片与表格 → 店小秘

进入“店铺上架”，选择“成品图片直接上架”，读取大文件夹中的一份 `.xls/.xlsx` 和图片子文件夹。选择店铺及每条商品母稿，核对货号、中英文标题、图片顺序。临时修改保存在本机，刷新后可恢复。

生成执行清单后点击“开始保存到待发布”。程序按条执行：读取母稿 → 引用模板 → 填货号/标题 → 上传主图 → 同序填写详情图 → 保留原 SKU 预览图 → 保存 → 重新打开核对。已完成条目不重复创建。保存结果不明时先在店小秘找到对应草稿，再点“核对现有草稿”，程序会比对保存前快照，匹配后才认领结果。

默认选择“仅保存草稿”，终点为店小秘“待发布”。也可明确选择“保存并发布”：程序保存、核验后提交发布，并记录回执；提交成功不代表 Temu 已审核通过或已在售。真实发布仍需有效商品单独验收，请勿把测试母稿中的演示价格、库存和运费缺项用于商业发布。

## 桌面体验回归（2026-11-09—10）

本轮通过 16 个桌面主流程检查点，覆盖空配置、两份长 ID 母稿、导入失败、不同商品选择不同母稿、构思、单图失败重试、结果核对、模拟 ERP 保存、刷新恢复、Excel 回导、1000×720 窗口，以及单品方案编辑和两张竖图结果恢复。214 项单元/集成检查、8 个表单回归场景、桌面启动检查和单品快/大师模式检查均通过。

修复了保存提示被顶栏遮挡、下一步按钮层级不明确、旧提示残留、首图排序禁用状态被覆盖、新手引导打断填写，以及单品设计方案不可见的问题。首次配置增加直达入口，并按依赖顺序排列设置导航。单品页可展开“查看并修改本套设计方案”，方案修改会保存在本机，刷新可恢复。

本轮运行的是开发版 Electron。图片、标题与 ERP 使用测试替身；系统文件夹选择只验证桥接返回值。未调用付费模型、未写入真实 ERP、未执行正式发布，也没有重新构建或验收分发安装包。完整截图与记录见项目外层 `outputs/desktop-experience-20261109/`。
