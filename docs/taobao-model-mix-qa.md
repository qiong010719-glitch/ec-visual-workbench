# 固定模特与混合分镜修复（2026-11-21）

用户真实截图显示，5张主图与2张SKU都被改成同一人物站在商品旁的展示海报。此前实现把固定身份错误地等同于每张出镜：覆盖无人/手部分镜，删除混合展示约定，并向每个生成请求附加人物参考。

## 本轮改动

- 保留原有分镜的场景、动作、镜头、商品比例、构图和信息重点。启用固定模特时不再重写这些字段。
- 首张主图可由模特辅助展示；其他图片沿用逐图人物安排。人物镜头复用固定身份，手部镜头只匹配肤色/袖口、不要求露脸；无人图片不传模特参考。
- SKU只展示对应商品及规格，不带人物参考。商品、人物、对标仍各自标记用途。
- 构思与实际生图提示词使用相同的逐图安排，服务端记录每张的实际人物类型和参考角色。
- 新规则带独立版本号。旧全人物方案在提交收费和派发前被拒绝，提示重新构思；已有成图和已选模特保留。页面也阻止旧后端静默执行。
