# 跨境工作台玻璃界面

2026-11-21

## 使用

已有多平台预览运行时，打开 http://127.0.0.1:4196/cockpit.html。
下次运行 `启动多平台预览.cmd`，桌面应用默认进入新总览；浏览器 `/` 与 `/app` 也进入总览。
当前运行中的服务不用重启即可使用 `/cockpit.html`；根路由和桌面默认入口在下次正常启动生效。

总览、商品库、选品与采集、内容制作、上架中心、任务记录、连接设置共用侧栏与主题。
原有页面的业务 DOM、数据保存和执行器保持原接口。

## 总览行为

- 通过 `/api/workspace` 读取真实商品、任务、平台版本及店铺。每 30 秒和回到页面时刷新。
- 待办数包含正在进行以及需要人工处理的任务；已完成任务不计入待办。
- 平台成品只统计状态为 `completed` 的版本。数据不存在时显示 0；读取失败时保留已有数据并提示重试，首次失败显示破折号。
- 六张功能卡支持点击选中、左右键、拖拽吸附、明确开启/暂停自动浏览及平面视图。卡片与详情使用同一选择状态。
- 单击只选择卡片；双击、卡片下方入口和右侧按钮进入现有功能页。总览不发起生成、采集、保存或发布请求。
- 搜索覆盖功能入口、商品名称/资料、任务名称/类型。
- 外观包含深/浅色、三种强调色、流体材质和动态效果开关；以 `commerce-cockpit-appearance` 保存浏览器偏好。
- 遵循系统减少动态效果设置；无 WebGL 时保留静态玻璃背景和全部业务入口。标签页隐藏时停止动画。

## 2026-11-22 首屏切换修复

页面初始 HTML 直接包含玻璃侧栏和布局 class，主题偏好由 head 中同步执行的 `workspace-appearance.js` 读取。
通用外壳及业务样式是初始 HTML 的阻塞式样式表。延迟执行的 `workspace-shell.js` 只绑定已存在的导航、菜单和同步事件，不再次替换导航节点。
因此切换板块不会先显示旧 Temu 横栏再换成新版；修复通过每次请求读取的静态页面立即作用于已运行服务，无需重启或更新业务数据。

共享导航模板为 `public/local/workspace-shell.html`。修改模板后运行：

```powershell
node tools/sync-workspace-shell.mjs
node tools/check-source.mjs
```

源检查会验证七份页面的初始导航、主题入口与样式引用同步。单品设计页面的 `macTitlebar` ID 保留。
首屏测试刻意延迟业务脚本和样式，在首次绘制起逐帧检查旧导航、背景、主题和布局；证据放在当时本机项目工作区的 `outputs/navigation-flash-fix-20261122/`。

## 2026-11-21：第一版真实 3D 与开场（历史记录）

新增 `cockpit-scene.js` / `cockpit-scene.css`。中央舞台现在使用本地 Three.js r187 的 WebGLRenderer、透视相机、六个有倒角与厚度的卡片网格、独立立体图标、环境灯光与轨道。玻璃采用透明混合与 clearcoat 高光，未启用昂贵的实时折射传输。原 CSS 卡片保留为键盘导航和故障回退。

每次打开总览，动态偏好开启时播放约 3.85 秒的 5200 粒子球开场，随后工作台分层入场。支持跳过、Escape 和页首“重播开场”。减少动态效果、关闭动态效果、页面不可见时不会强制播放。数据加载独立于开场。

拖拽连续旋转，释放后吸附；点击通过 raycaster 选中实际网格，详情及入口沿用原数据绑定。窗口与舞台尺寸改变时调整相机；WebGL context 丢失后恢复原卡片、尺寸及选择状态。页面离开时释放 WebGL、观察器、监听器和贴图。

本轮实际检查：语法/静态引用检查、浏览器真实渲染、粒子成球、跳过/重播、拖拽、方向键、平面切换、详情联动、动态偏好、390px 窄屏，以及主动丢失 WebGL context 后的导航回退。最终恢复正常渲染，控制台 error 为空。未重新运行上节两个独立 browser 脚本。

Node 全套初跑 334 项，332 通过；旧首页断言 `/products` 已按当前路由修正为 `/cockpit.html`，Temu 10 项重跑通过；另一个 250ms planner deadline 测试在并行运行中失败，未修改实现，单独重跑所在文件 12 项全部通过。未再次把这些结果表述为“全套单次通过”。

此次验收截图及说明在当时本机验收工作区的 `outputs/cockpit-3d-repair/`。Three.js 来源、固定版本与 MIT 许可保留在 `public/vendor/three/`。

## 2026-11-21：材质、粒子和交互升级（当前版本）

仍采用 Three.js r187 / WebGL2，新增本地 EffectComposer、UnrealBloomPass、OutputPass、FXAA。卡片 transmission 从第一版的 0 改为 0.98，结合厚度、折射率、体积衰减、倒角、清漆和程序生成的浮点环境光照；没有使用远程 HDRI、模型或付费生图。六种功能图标均为实体网格，文字保留稳定的深色底板。后排卡片抬高缩小，选中卡片前移，悬停轻抬与倾斜。

开场约 5.15 秒：18000 个球壳粒子聚合，着色器流场形变、大小及明暗差异、五条带运动亮点的轨迹、氛围光、镜头推进与鼠标视差，最后散开入场。粒子流场属于视觉着色器，不是流体物理仿真。保留跳过、Escape、重播、关闭动效与系统减少动效。

拖拽释放按速度预测最近卡位，再用阻尼弹簧吸附。光线投射选中、方向键和现有详情路由继续使用同一状态。交互结束后中央舞台停止持续重绘，新的交互触发更新；开场期间暂停被遮盖的顶部流体动画。慢帧情况下适当降低像素比及透射缓冲分辨率。平面视图切回时清除舞台内部滚动，3D 模式使用 overflow:clip，避免隐藏键盘目标引起画布偏移。

本轮实际验证：42 个页面脚本及静态资源检查通过；2560×1271、默认窗口和 390×844 的真实浏览器渲染；开场与重播、拖拽、键盘选择、详情/路由联动、平面切换、关闭动效仍可选择、系统减少动效、主动 WebGL context 丢失后的回退。恢复普通窗口和动效后截图完成。最终控制台没有 error；Windows ANGLE 对上游 FXAA shader 有编译 warning，当前渲染成功。没有承诺固定 60 FPS，也未把上次全套 Node 测试结果计为本轮重跑。
