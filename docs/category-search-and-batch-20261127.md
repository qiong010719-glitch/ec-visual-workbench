# 中文分类搜索与原生批量处理核查

## 本次可以使用的改动

- SHEIN 分类从当前店铺的可见中文搜索结果读取，展示完整路径；搜索结果的本地候选引用与真实平台分类 ID 分开保存。
- 提供具体商品类型、用途和逐件勾选；同店、同完整来源分类且确认属于同类型的商品可共用一次分类选择。不同平台、店铺、站点、经营模式的确认记录隔离。
- 候选必须经过确认；排序建议不等于已确认分类。过期候选、来源变化和重启后需重新读取，不能使用旧候选直接提交。
- 分类后的动态必填字段与选择框、填空字段分开处理；价格保持店小秘现有金额、币种和 SKU 对应关系，不再次计算汇率。

模型排序在配置了规划模型地址、凭据和模型名时可接入，并只排序真实候选；未配置时使用本地判断。本次验证使用隔离替身，未实际调用付费模型，也未把模型建议当作已确认分类。

## 原生批量仍未开放完整自动处理

当前观察到的 SHEIN 原生主表可读取标题、描述、SKU、价格、库存等列，但没有完整展示产品分类路径及普通类目属性。变种主题不是普通类目属性，不能据此认定所有必填项已经读全。

`nativePrepare`、`nativeSave`、`nativePending` 继续为 `false`。对应控制器和服务端均在浏览器写操作之前拒绝不支持的完整批量处理。没有用逐件保存替代原生批量来宣称功能完成。

当前分类搜索入口仅适配 SHEIN；其他只有逐级目录的平台仍可逐件确认，尚无首次具体类型批量确认入口。独立编辑页若未暴露已知的真实分类 ID，也会保持待核对，不退化为仅比名称。

已建立但尚未对真实商品启用的原生控制流程：精确选择本批商品 → 分类与变种对应 → 读取属性及动态空项 → 一次原生保存 → 独立逐件只读核对 → 一次批量移入待发布 → 核对。分类保存、商品保存及移动各有独立提交记录，回执不明不能重复发送。

新增核对包含：分类前后的原始价格；完整 SKU 与所有价格控件覆盖；保存前后已有内容和本次填写值；批次、账号、店铺及草稿身份；保存按钮的实际坐标和点击前提交记录。分页、虚拟行、遗漏或隐藏价格控件均不能作为完整证据。

## 搜索前确定类型的建议

搜索前先确定具体商品类型；已经确认的目标店铺末级分类可以作为预设。搜索后仍检查每件结果是否符合该类型，配件、其他用途和重复商品不计入本批目标数量。按目标平台、店铺、站点、经营模式和末级分类分组后，再批量填写。

第一次遇到的新类型仍需从该店铺的真实目录取得分类候选。不能把 Temu 搜索词、Temu 分类或另一个平台的分类直接当作目标店铺分类 ID。

本次没有把搜索前分类设置做成强制新增表单。提前分类可以减少选类次数，不能补足尚未适配的原生属性编辑入口。
