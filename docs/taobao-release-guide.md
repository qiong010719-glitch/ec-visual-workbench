# 淘宝视觉壳：本地使用与交付

本说明只适用于独立淘宝目录 `D:\agent合集\自动上架\ec-visual-workbench-taobao`，服务为 `http://127.0.0.1:4173/`。当前仍是叠在 PR #7 上的 draft PR #8，未合入 main，没有发布到淘宝或公网。其他工作台不属于本项目。

## 继续查看真实案例

打开工作台的「草稿箱」，选择「整套十图实测 · 100cm与140cm餐边柜」，点击「继续编辑」。已保存 5 张主图、2 张 SKU、3 张详情，本品素材、两款 SKU 素材、风格、逐图要求、构思文字及对标绑定均可恢复。另保留「Apify三图实测 · 落叶胡桃奶油白餐边柜」。

切换前若当前工作台有内容，会新建一份「切换前自动备份」。恢复前先核对引用图片是否存在及 SHA-256；缺失或变化时停止，不覆盖当前工作台。恢复与刷新不会抓取、分析或生图。进行中的任务完成前不允许切换。只在同一本地服务中恢复，不把本机草稿误称为淘宝店铺草稿。

## 日常操作

1. 填写本品名称、已确认的外观与卖点，上传本品主体图。每款SKU在同一卡片上传或选择本款图片，并可填写名称、实物尺寸和单位。没有SKU图时至少填写一项已知尺寸。
2. 选主图、SKU、详情张数及画幅，填写「逐张要求与参考图」。首张主图可用生活场景，白底为自选；没有文字拖动功能。
3. 如需对标，粘贴淘宝／天猫链接，用 Apify 读取图片；检查抓取商品是否正确。按主图、SKU、详情分类，为需要参考的输出绑定原图。对标仅参考版式，本品与 SKU 图决定商品。
4. 点击「分析并用于构思」，查看分析状态，再「一键构思」，逐张核对方案。只有决定出图时才点击「开始生成」；修改要求不会自动重做旧图。
5. 查每张成图的商品结构、规格、中文、品牌与未确认承诺。有问题只调整对应图片，不把“接口成功”当成“成图合格”。本次尺寸图改用文字规格栏，避免生成的进深箭头误指柜脚。
6. 「草稿箱 → 从当前工作台新建草稿」保存当前版本。单张「下载原图」、图库「一键打包下载」保留返回文件原字节及实际尺寸。构图目标宽高不等于供应商实际像素。

SKU 图用于确认具体款式和规格：完整商品应为主体，保留绑定上传图里清晰的尺寸、单位和颜色，清理手机/购物界面，不自动生成卖点拼版。先设置SKU张数，再分别在对应卡片提供图片和信息；每款只使用自己绑定的图片，不自动重复其他款图片。更换 SKU 参考、修改输出职责或恢复旧版 SKU 方案后，需要重新构思再出图，旧图不会因此删除。构思后的文字方案不等于已识别图片规格；实际生图仍需核对原图尺寸和结构，模型重绘不保证像素保真。

每款的名称/款式选填，尺寸单位为mm/cm/m，长、宽、高、深/厚只填已知项。有图片时可补充信息，填写的名称和尺寸优先于图中同项内容；没填的项目只保留图中清晰规格。没有SKU图时，至少填写一项实物尺寸，使用产品主体图保持外观，不借用别款图或尺寸。图片、名称、尺寸和单位随刷新与完整草稿保存，修改后须重新构思。减少再增加张数保留各款数据；移除图片不删除已填信息。该功能不代表已完成全部商品参数填报或自动上架。

需要人物时，在“是否模特出镜”选“是”。模特来源可选“客户上传”或“系统生成”：上传单人清晰照片，或填写外观/服装要求、确认费用、生成1张候选，再点击“使用这位模特”。切换来源不自动换人，生成候选不自动替换已选人物。首张主图由模特辅助展示，其余按原分镜区分人物、手部、静物和细节；SKU不添加模特。只有人物/手部镜头附带同一人物参考。更新前的全人物方案须重新构思，已有图片和模特保留，无需重新生成模特。草稿与“图片／视频共用模特包”保留原图和身份。AI视频尚未接入，共用参考尚需真实成图及逐镜头验收，详见[客户交付进度](taobao-delivery-roadmap.md)。

草稿「导出 ZIP」包含商品 JSON、设计方案、SKU CSV 和当前成图。它是交付资料包，**不是可跨电脑一键还原的完整数据库备份**；没有打包本品上传图、对标库、任务库，也没有导入功能。迁移/备份需在服务空闲并停止后，完整保存本项目 `data/`；其中有私有素材，不随源码交付。

## 配置与费用

当前机器已通过既有本地启动器载入凭据。本次没有读取、打印、编辑或打包 `.env` 密钥。源码包不含凭据，也不会继承另一台电脑的服务账户。

| 用途 | 服务端进程配置 | 已确认行为 |
|---|---|---|
| 生图 | `SUANZHOU_IMAGE_API_KEY`、可选 `SUANZHOU_IMAGE_BASE_URL` | 算舟兼容图片接口，当前 `gpt-image-2`，不自动换供应商 |
| 构思 | `PLANNER_API_KEY`、`PLANNER_BASE_URL`、`PLANNER_MODEL` | 无配置时使用本地规则；“已配置”不代表在线可用 |
| 版式分析 | `VISION_*`，缺省沿用已配置的文字/视觉通道 | 发送选择的真实图片，费用单独计算 |
| 抓取 | `APIFY_API_TOKEN` 或 `APIFY_TOKEN` | 单商品，不取评论，每次运行上限 $0.05 |

费用以供应商账单为准。此前抓取记录 $0.0178；这轮复用该资料，新增抓取/分析均为 0，构思 1 次，生图 10 张加明确修订的 2 张 SKU。没有取得构思与图片的供应商实扣账单，不能把页面点数当金额。

失败时先看任务状态。Apify 有运行编号时可「同步已有抓取」；提交结果未知且没有运行编号时先查原运行，不换任务号重下单。图片已经生成但下载失败时，用下载恢复入口取回已有结果；超时不自动重做图片。

## 本地启动、源码包与回退

- 当前服务继续使用已配置启动器 `runs/taobao-configured-service/start.ps1`，只供本机使用，不在源码包中。
- 新环境需要 Node.js 22+；如配置图片下载代理，需要 Node.js 24.5+。安装项目依赖后由操作者向进程提供自己的凭据，显式设置 `PORT=4173`，运行 `npm.cmd start`。先确认端口属于本项目；不终止其他工作台服务，不使用 4185。
- `python tools/package-source.py` 在本仓库 `runs/source-release/` 生成源码 ZIP 和逐文件 SHA-256 清单。只收录跟踪中的程序/说明/测试，排除所有 `.env*`、运行数据、抓取素材、生成图片、浏览器配置及测试产物。
- 修改代码前保存草稿；回退先停止本项目空闲服务，保留整个 `data/` 备份，然后仅回退本项目代码。旧版本看得见已有商品资料和成图，但没有新版本的完整“继续编辑”入口。不要删除数据库，不使用会清除本地素材的清理命令。
- 本地交付不等于生产上线；多人协作、跨电脑恢复、其他商品/天猫的真实稳定性、公开部署均未验收。合并 main 必须等待用户明确说“合”。
