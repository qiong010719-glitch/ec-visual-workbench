# 免费选品：按店小秘模板批量认领

需求与录屏核对时间：2026-11-21，已按用户最新阶段说明修订。本文件只说明采集后的认领分发，尚不表示该功能已经接入或再次执行了真实认领。完整阶段设计见同目录 `free-sourcing-linkage-walkthrough.md`。

## 用户要求

选品采集时，工作台只需选择来源前端平台、输入关键词和采集数量，不要求选择上架店铺或认领模板。

用户此前要求在店小秘人工建立并维护认领模板，将平台、店铺及相关站点绑定到模板；该联动放在采集后的认领分发阶段。关键词这一批商品确认进入“产品 → 通用服务 → 数据采集”后，再通过批量认领，分配到所选模板绑定的各平台、各店铺采集箱。

此处模板是“选择店铺-认领到采集箱”弹窗右侧的店铺组合模板，例如“画板”“电器”。它与平台采集箱后续使用的产品模板、变种模板、运费模板，以及工作台既有商品母稿配置分别处理。

进入目标平台采集箱以后，用户再选择要处理的店铺和商品，批量补全缺失资料，然后上架到对应店铺。认领到采集箱是当前阶段的完成点，采集箱到上架仍需继续实走并程序化。

## 工作台对应流程

- 采集表单：来源前端平台、搜索关键词、采集数量。店小秘账号属于连接设置，上架店铺不属于采集输入。
- 认领分发表单：已采集批次、店小秘认领模板；选择模板后展示目的平台、店铺与站点摘要。
- 模板列表从已连接的店小秘账号读取；人工修改模板后可重新同步。认领阶段记录所选模板及其目标集合，恢复时不能静默换成其他模板。
- 一批关键词采集完成并核实后，只选取本任务对应的通用数据采集记录；不通过列表全选将无关商品一起认领。
- 提交前核对店小秘实际模板与工作台选择一致。模板消失、重名或绑定变化时应说明差异，避免发往错误店铺。
- 认领结果分别记录商品数、目标店铺数、成功数、失败数及重复跳过数。未知结果先核对认领记录，避免重复提交。
- 本段终点是目标平台采集箱中的对应商品。之后进入平台采集箱选择店铺，再进行批量修改、资料补全和发布；认领成功与上架成功分别记录。

## 现有实现的整合边界

现有 `dxm-claim-browser.mjs` 用于单店认领，主动清空其他选择并拒绝已选模板，不能直接调用以实现此需求。需新增模板读取、批次精确选择和模板批量认领能力。

免费选品已有入箱证据应保留；认领状态另行记录。认领后商品可能不再出现在“未认领”分类，恢复时应从全部记录及认领历史核对，不应再次点击采集插件。
