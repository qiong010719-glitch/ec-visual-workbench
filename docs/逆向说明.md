## 接口契约

原前端的网络调用、请求字段、Firebase 路径与回调分支均可直接读取。下面重建的是接口行为，不是取得了原站服务端源码。

| 原接口 | 核心输入 / 输出 | 本地处理 |
|---|---|---|
| `POST /api/agent` | 产品资料、参考图、范围、`agent_task_id`；等待 `agent_tasks/<id>` | 规则/可选文本模型构思，保存方案 |
| `POST /api/generate` | `sop_text`、`categorized_images`、`firebase_tasks`、逐张要求 | 每槽位独立生成，限制并发 |
| `POST /api/ultra_generate` | 产品资料、整套范围与任务 | 合图提示词与独立图片任务 |
| `POST /api/inpaint` | `task_id`、`prompt`、底图或 base64、素材与比例 | 算舟参考图编辑 / 无参考图生成 |
| `/api/generate` 手机分支 | `mobile_reformat: true`、`tasks[].source_image_url` | 逐张手机 A+ 重排 |
| `GET /api/orders` | 余额、订单记录 | 测试点数与本地任务账本 |
| `POST /api/refund` | `request_id`、`refund_key` | 仅失败任务，幂等退回测试点数 |
| `POST /api/feedback` | 评分、单图差评、图片归档、报告 | 本地保存，不向飞书发送 |
| `POST /api/alipay/create` | 支付金额 | 返回明确的未配置状态 |
| Firebase Storage / 图片中转 | 上传 blob、返回可读取图片 URL | 本地 `data/media/` |
| Firebase Realtime Database | `ref(...).on('value')` / `.off()` | 兼容适配到本地轮询 API |

本地新增 `/api/session`、`/api/status`、`/api/tasks/...`、`/api/media/up`、`/api/drafts`。服务仅监听 127.0.0.1，写入请求检查本机会话标记及来源，静态文件服务限制在公开目录和媒体目录。

## 明确无法从公开页面恢复

1. Vercel API 服务端实现、原始 Git 仓库、n8n 节点与私有提示词。
2. 原服务各模型的精确编排、提示词策略、私有训练与真实计费逻辑。
3. 用户账户、授权白名单、订单、私有图片、商户密钥与回调签名。
4. 原站未提供的 PSD 导出；公告中的待上线文案不构成实际功能。
5. 未出现在前端调用中的店铺自动发布能力。

本地默认方案依赖规则，不能声称复现了原服务的生成质量。真实算舟和可选文本模型尚未实测；测试结果只证明本地界面、接口、状态和资料处理流程。

## 本地适配修正

- 将图片裁切中的外部代理路径改为本地媒体读取，避免把 `/media/...` 地址发送给第三方图床。
- 恢复极速模式、对应输出范围和专用结果槽位；恢复正在执行的极速任务时使用正确监听器。
- 存档读取完成前禁止把启动时的空表单写回，避免覆盖此前产品资料。
- 让构思结果真实填入 SOP 并解锁生成按钮；原公开前端的完成分支仅处理了状态动画。
- 手机 A+ 重排按原页面 `tasks[]` 契约处理，并支持原上限 20 张，每张只使用自己的来源图。
- 补上专用图片密钥检查；未配置时在提交任务前显示缺项。
- 真实收费文案改为算舟账户额度说明，本地测试点数与第三方实际账单分开。
- 原版已落到本地的结果图直接复用，避免重复上传或重新保存副本。

上述修改由 `tools/adapt-frontend.mjs` 和 `public/local/` 管理，可对照保留的参考快照检查。

## 与本项目原有上架规则的关系

新增草稿始终 `status: draft`、`published: false`，没有发布 API。没有执行上级目录已有商品的新建、修改、保存、删除或发布。测试 SKU 使用独立验收数据，不沿用历史产品的单次模拟授权。自动化浏览器验收通过项目的 `interaction.mjs` 使用必要操作间隔 2.5 秒，并输出间隔记录。
