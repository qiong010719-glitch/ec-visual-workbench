# 重复商品跳过并补足新增数量

2026-11-25：用户要求遇到插件按钮显示“重复采集”时跳过，继续采集其他商品，直到新增成功数达到输入数量。

## 修复

- 识别唯一可见店小秘固定面板中的“重复采集”控件，采集前直接记录重复回执，跳过且不点击该控件。商品正文、面板外文案、隐藏控件及多个无法唯一确认的面板不作为重复证据。
- 新提交成功后按钮也可能变为“重复采集”。新鲜的成功提示仍算本次成功；仅按钮变化不能证明提交后出现重复，不据此丢弃未知提交记录。明确的网页或原生重复提示仍按原逻辑跳过。
- 目标数量为成功采集数。重复、不可用商品不占目标；已提交但结果未知的商品先占一个待核对位置，避免继续补充造成超量或重放。
- 用原关键词及已有搜索页补充候选，排除本批已处理的商品编号，保持主列表顺序和原始链接。不做采集箱前置查重。
- 补充时允许处理少于剩余目标的可用候选；当前页有限加载后仍无新商品则保留进度，明确提示缺少数量，不误报完成。不自动翻页。
- 成功提示先保存，再返回搜索页；整批结束后核对入箱记录。重启及验证恢复不会再次采集已跳过或已提交的商品。
- 页面输入框更名为“本次新增采集数量”，并说明重复不占数量、候选不足时的行为。
