# 跨境电商工作台改造

六个入口共用一份商品、平台版本、连接设置和任务数据：商品库、选品与采集、内容制作、上架中心、任务记录、连接设置。单品设计属于内容制作，上架中心保留图片裂变上架与自动选品上架两种模式。

## 已实现的行为

- 单品设计可选择 Amazon 或 Temu。Amazon 沿用主图、附图、普通 A+、高级 A+、自定义及手机排版流程；Temu 沿用现有主图与详情同图同序规则。
- Amazon 当前工作台预设：主副图 1024×1024、普通 A+ 970×600、高级 A+ 1464×600、手机 A+ 1200×900。按比例留白适配并另存模型原图；这些是本工作台的输出预设，不代表所有类目都要求同一尺寸。Temu 新图继续使用原有 1:1、1024×1024、单张不超过 2 MB 的处理链路。
- 原图归属于公共商品；同一商品可同时保存 Amazon 和 Temu 多个成品版本。刷新页面可继续原任务，已完成的图片直接交给上架中心，不要求再次生图。
- 店铺的平台、站点、ERP 和浏览器连接统一在连接设置管理。上架平台选项取自已绑定店铺。新增连接会刷新其他入口的可选项，已开始的历史批次仍保留原始绑定。
- Amazon 店铺可绑定和制作、核对、导出商品资料。当前自动发布执行器仍仅支持店小秘 Temu，不会把 Amazon 请求交给 Temu 执行器。
- 选品页面隐藏“极鲸云 / GeekBI”品牌展示，改用中性名称；接口、外部控制台地址、计费说明和已有凭据配置保持有效。原选品与采集逻辑独立保留。

## 兼容与数据

统一数据索引写入已有 `workbench.json` 的 `workspace` 字段，历史商品批次、图片组、草稿和任务以引用方式汇总。读取工作台不会重新生成、重建旧批次或重放上架。

旧 `/temu`、`/temu/listings` 与 `/api/temu/erp/*` 继续兼容；新入口 `/design?platform=amazon|temu`、`/listings` 使用这些服务完成既有操作。ERP 执行器、原图读取/输出打包和发布回执处理保持原实现。多窗口保存带版本校验，冲突时保留未同步草稿供恢复。

## 独立预览与验证

`启动多平台预览.cmd` 使用独立数据目录 `../desktop-preview-data` 和端口 4196；`node tools/start-multiplatform-preview.mjs` 使用 `../preview-data` 和端口 4195。预览不会导入原工作台密钥或连接配置，不会重启原来 4185 端口的工作台。

自动化验证使用临时目录、模拟图片服务、模拟 ERP，并阻断浏览器外部请求。运行 `npm run check`、`npm test`；浏览器回归包括 `browser-design-platforms.mjs`、`browser-workspace-ui.mjs`、`browser-workspace-flow.mjs`、`browser-publication-recovery.mjs`、`browser-workspace-recovery.mjs`。测试结果不代替真实平台发布验收，详细记录见 `multiplatform-validation.md`。

本次修改在独立 Git 工作副本完成。另一对话修改的选品源码保留为整合基线；合回仍在工作的原目录时，只应用本次增量，保留另一对话之后的新增内容。正在运行的正式实例不在本次验证中切换。
