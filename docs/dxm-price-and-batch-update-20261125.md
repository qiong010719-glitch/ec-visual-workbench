# 店小秘价格保留与批次处理修正

## 用户确认的规则

店小秘会在采集、认领到平台店铺时自行换算价格。工作台保留该商品各规格的现有价格，不再次换算，不用默认值填价格，也不声称校验了店小秘所用汇率。分类按真实平台末级目录确认；其他普通必填属性可采用当前表单允许的默认值，保留已有有效值及品牌、资质等身份资料。

## 已接通

- required-fields 模式保存前读取店小秘当前 SKU 价格，固化在保存意图中；保存后及移入待发布前核对价格、币种和规格是否保持一致。空价、异常价、SKU 范围变化会留下具体问题。
- 普通属性支持可见选项和合法数值默认值；分类和价格不进入普通默认填充。
- 分类目录兼容已观察到的中英文路径表示，保留真实分类编号；重名或父级不一致不猜选。
- 分类批量应用仅限同店、同来源完整分类、尚未保存的商品。确认映射按账号、平台、店铺、站点和经营模式隔离。
- 个别商品未选分类时，已满足条件的其他商品仍可通过兼容操作继续。未知保存/移动结果仍先核对，不重复提交。
- 新采集记录可见来源分类、选中规格及价格对照；旧批次可只读补读。来源价格缺失不会阻断保留店小秘已有价格。
- SHEIN 新增“打开本店原生批量编辑”：只选已定位且未保存的本批店铺草稿。该动作只打开页面，不保存商品。
- 重复点击同店同范围原生入口会保留已有打开记录；切换店铺再返回也不会新开同批页面。批量回执若声称已保存却缺少提交记录，整组标为未知，禁止再次发送。

## 真实边界

**原生批量自动填写、保存及批量移入待发布尚未完成适配。** 工作台返回 `nativePrepare=false`、`nativePending=false`，不展示连续原生处理按钮，也不以逐件循环冒充原生批量。原有逐件兼容操作在界面中明确标注。

现场已确认 SHEIN 的原生批量编辑入口：未对应分类会出现前置提示，跳过会丢失变种信息。本次没有跳过、保存或发布真实商品。原生批量完整表单尚未取得可用的现场结构和独立保存回读样本；当前实现仅包括精确选择、入口检查及保留待核对页面。

Temu 来源页在只读核查时出现安全验证，原有页读取也遇到连接超时。来源读取器已做隔离 DOM 测试；未观察到的实际布局明确返回资料不全，不能视为现场布局已验收。

## 恢复与验收

重启不自动续跑。任务保留原商品范围、店铺绑定和既有提交证据；先核对，再由用户选择后续操作。新代码未执行真实采集、认领、保存、移入待发布或发布。

测试覆盖价格不二次换算、不被普通默认值覆盖、价格回读变更、分类路径差异、批次范围、互斥、未知结果和重启恢复。针对原生入口的测试仅证明隔离页面行为，不能代替完整原生批量的现场验收。
