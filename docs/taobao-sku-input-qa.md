# SKU规格来源双模式（2026-11-21）

原“还没有SKU图”是上传数量状态文字，不是可点击选项。本轮增加两个真正可切换的模式，保留上传图、旧成图和已填写的数据。

| 模式 | 用户提供 | 生成使用 |
|---|---|---|
| 有SKU图 | 按规格顺序上传SKU图 | 对应上传图的商品、清晰尺寸、单位和款式；清理截图界面，不做卖点拼版 |
| 没有SKU图 · 填写尺寸 | 产品主体图；每个SKU可选名称、单位和至少一项长/宽/高/深或厚 | 本品外观加当前SKU手填实物尺寸，默认规格文字栏；不使用未启用的SKU图或其他SKU的尺寸 |

实物尺寸使用mm/cm/m，与原有构图目标像素分开。未知尺寸留空，不自动猜测。尺寸输入数量随SKU张数变化，减少再增加数量仍保留原数据。切换模式、刷新和完整草稿恢复保留数据；另一模式的数据不参与当前请求。

服务端在文字构思派发前校验规格来源、单位、有效尺寸和商品参考；生图前再次校验。尺寸、单位、名称、规格来源或参考图与构思不一致时要求重新构思，不提交旧规格图。旧版没有新字段的草稿仍能读取；新界面采用明确来源，首次使用需要重新构思。服务能力版本用于阻止新页面向旧服务静默提交被忽略的尺寸。

验证包括：200项Node自动测试与25个页面脚本检查；隔离浏览器验证两种模式可点击、缺图/空值/零值拦截、两SKU尺寸不混用、模式切换、上传按钮、刷新、数量变化、草稿恢复、旧方案阻断后保留成图、按上传图重新生成和旧服务能力拦截。同时回归固定模特流程，SKU不附带模特参考。
