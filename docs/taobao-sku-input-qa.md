# SKU图片与规格合并输入（2026-11-21）

按客户反馈，取消“有SKU图／没有SKU图”二选一。每个SKU保留独立卡片，同处上传、更换或选择本款参考图，填写名称/款式、尺寸单位和长/宽/高/深或厚。

| 本款提供的资料 | 生成使用 |
|---|---|
| SKU图片＋填写信息 | 图片决定商品外观；填写的名称、尺寸和单位优先于图中同项信息。未填写项仅保留图中清晰可辨的本款规格 |
| 仅SKU图片 | 使用本款图片及清晰规格，不强制补填尺寸 |
| 仅填写尺寸 | 至少一项已知实物尺寸，配合右侧产品主体图，不借用别款SKU图片 |

实物尺寸为mm/cm/m，与构图像素分开。未知项留空，不猜测。每款图使用素材固定ID绑定，删除其他素材引起文件名重排也不会换款；不再自动重复最后一张图。删除绑定图而未明确清除绑定会阻断提交，避免悄悄改用产品主体图。上传更换失败保留原图与信息；全套参考图上限仍为8张。

减少再增加SKU张数、刷新、完整草稿恢复均保留图片绑定与信息。旧双模式草稿可读取：旧有图模式迁移已有对应图片，旧手填模式保留填写信息，原图库图片可从卡片内重新选用。统一输入为版本2，旧计划与更新后的来源、名称、尺寸或单位不一致时须重新构思；已有成图保留。旧页面或旧服务能力不匹配时阻断，防止静默遗漏信息。

验证：202项Node自动测试、25个页面脚本检查、7组SKU隔离浏览器流程。浏览器核对实际控件上传、两SKU图片与文字同时进入模拟请求、缺项拦截、固定ID在删除后不串款、现有图选择、混合有图/无图、数量变化、刷新、草稿恢复、旧方案保护与旧服务阻断。固定模特流程另做回归，SKU继续不带模特。
