# 谷歌窗口与端口设置

在“连接设置”中管理工作台专用的谷歌窗口。每个窗口有自己的名称、端口和登录资料，ERP 连接选择其中一个窗口；商品制作、上架和选品继续使用同一份连接设置。

## 操作方式

1. 选择一个已保存的谷歌窗口，或点击“新增独立窗口”。
2. 填写窗口名称和连接端口。可以自行填写，也可以点击“选择空闲端口”。
3. 点击“检查端口”查看当前是否可用；检查只读取本机端口和进程信息。
4. 点击“保存并应用”。保存成功后，再在 ERP 连接中选择这个窗口并保存 ERP 连接。
5. 需要登录时，使用该 ERP 连接的“打开店小秘登录”。

选中窗口、填写端口、检查端口都不会启动浏览器。保存时会再次检查端口占用与配置版本，成功后其他入口读取同一份新配置。

## 窗口与任务的关系

- 新增窗口会创建独立的登录资料目录；已有窗口及 ERP 绑定保留。
- 修改正在运行的专用窗口的端口前，需要先关闭该窗口。工作台不会自动结束谷歌进程，也不会接管其他窗口正在使用的端口。
- 修改已有 ERP 使用的窗口配置后，需要重新核对相关店铺母稿。已经开始的历史任务保留启动时的连接绑定，不会自动转移到新窗口。
- 有生成、上架或选品任务正在执行时，允许检查端口，但需要任务完成或暂停后才能保存连接修改。
- 这里选择的是工作台保存的专用谷歌窗口。普通谷歌窗口没有启用对应调试端口、或使用其他登录资料目录时，不能仅凭端口号接管。

## 实现范围

新增的端口检查、空闲端口选择和单窗口保存使用独立的 `/api/settings/chrome/*` 接口；原连接数据结构和 ERP 执行链路保持兼容。保存只合并当前窗口，不覆盖其他窗口、ERP、店铺或模型设置。检查失败、端口冲突或版本冲突时保留页面填写内容。
