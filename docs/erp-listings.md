# Temu 店小秘草稿工作流

入口 `/temu/listings`。在上级目录双击 `启动上架工作台.cmd`，默认打开 `http://127.0.0.1:4185/temu/listings`；同一服务的 `/temu` 为现有做图与裂变工作台。保留上级 `scripts/`、`config/` 与本项目的目录关系。

## 用户流程

1. 打开已配置的比特窗口并登录店小秘，在上架页面点击「检查连接」。
2. 选择目标店铺。母稿、站点和模板来自上级 `config/temu-stores.json`，已配置两家加拿大站测试店。
3. 选择一种素材来源：读取 Excel 与图片文件夹，或载入工作台已经完成的裂变批次 / 已保存的图片草稿。
4. 核对货号、中英文标题、图片文件夹。货号与文件夹名一致时自动对应；其他情况必须明确选择。可以排除图片和调整顺序。生成素材不编造英文标题，缺失时需补全。
5. 点击「生成执行清单」保存当前选择，然后点击「开始保存到待发布」。每批仅对应一家店。
6. 查看逐条结果。完成后可打开真实店小秘草稿；刷新页面可恢复执行记录。「暂停」会完成当前商品后停止下一条。

原 Excel、原图片和店小秘母稿不会被覆写。导入时生成不超过 2 MB 的 JPEG 工作副本，主图与详情图同图同序，SKU 预览图保留母稿原图。第四列及其他生成元数据保留在导入记录里，不擅自写入 ERP 字段。

## 当前范围

- 一批 1—20 条商品，每条 1—10 张图片；执行器逐条处理。
- 当前只接入已有配置的比特窗口，Temu 半托管加拿大站、风格单变种、单 SKU 母稿。
- 使用各店独立模板；执行前比较模板与母稿的类目、属性、产地和运输配置。模板过期或字段不同会停止。
- 母稿链接与店小秘保存的产品模板是两份关联配置。「母稿用途名称」只是工作台内的别名；「店小秘模板名称」必须对应已通过“存为模板”保存的完整名称，填写配置不会自动创建 ERP 模板。引用前按完整名称搜索并检查所有结果页，只允许唯一同名项；不存在或重复时提示具体原因，不再用子串匹配旧模板。连接设置可读取真实模板列表、在关联浏览器打开原母稿、单独校验绑定；新增或修改绑定保存时自动校验，成功后保留模板编号。构思或生图前重新核验本批使用的绑定，发布执行也会检查模板编号及必填运输字段。两边运费模板同时为空仍算失败。
- 复用母稿的价格、规格、库存与运输配置。待发布保存通过不代表商品已经满足正式发布条件。
- 支持「仅保存草稿」与「保存并发布」。发布提交、店小秘在线记录、平台审核和平台在售分别显示；测试不调用付费生图服务。
- 目前重复检查要求完整显示待发布列表；存在分页 / 筛选时会停止，避免不完整检查后重复创建。
- 图片生成、草稿保存、平台发布是不同状态。界面只有真实回读核验通过才显示「已核验」。

## 执行与恢复

执行状态在 `data/erp/state.json`，图片工作副本在 `data/erp/imports/`，真实页面证据在 `data/erp/runs/批次ID/货号/`。

批次绑定店铺、母稿、货号、标题及图片哈希。重复生成同一清单返回同一批次；重复开始不会重新创建已完成商品。保存前先写执行日志，保存结果不明确时标记「保存结果待核对」，禁止自动再次创建。服务重启后中断的保存也按此处理。

全局浏览器执行锁位于上级 `outputs/erp-execution.lock`。正常结束会释放。异常退出遗留锁时，应先确认没有任务运行、核对店小秘结果，再由维护人员处理锁；不要用删除锁强行开启并发。

如果只有页面填写失败、尚未提交保存，可以修复后从执行记录继续未提交条目。若已点击保存但核验失败，保留执行标签页、草稿 ID 和失败截图，先核对实际结果。

发布回执缺失或用户在店小秘手动完成发布后，点击「核对发布结果」。程序按原草稿的完整 ID 检查在线、发布中、发布失败及待发布列表，支持空列表与分页。18 位数字回执按原始字符串解析，不经浮点数舍入匹配。

店小秘返回 `dxmState=online` 但没有平台生命周期时显示「店小秘在线 · 生命周期待同步」，不推断平台已在售。确认在线或已提交后清除旧错误并恢复「继续未完成条目」，已完成商品不会再次创建或提交。只有待发布或查不到记录仍不能证明原提交失败，保持禁止自动重试。
