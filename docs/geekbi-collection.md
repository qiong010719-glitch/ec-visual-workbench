## 使用

1. 在“连接设置”配置谷歌浏览器和店小秘账号显示名，并在该 Chrome 登录对应账号。当前界面仅提供谷歌浏览器连接。
2. 在“自动选品上架”保存极鲸云凭据、选择站点和筛选条件。每个关键词查询第1页，预计每次10点；先看页面预计点数再查询。
3. 勾选商品并选择接收账号，查看原始详情预计点数，点击“获取详情并导入”。首次限1件，完整入箱核对成功后，该账号每批最多20件。
4. 在批次中查看详情扣点回执、原始币种、快照时间和错误原因。文件生成后可下载保留，也可打开已核对的店小秘商品。
5. 遇到详情缺失、币种/模板不匹配、账号不符或不明确结果时停止后续条目。“只核对入箱结果”不请求付费详情、不重新上传；店小秘已认领或改过的记录不会自动覆盖。

## 实现边界

- 查询与批次状态保存在用户数据目录 `sourcing/`；保留供应商返回字段和接收时间，不让模型生成商品事实或改写图片、标题、规格。
- 请求编号幂等。付费查询超时、浏览器提交后断线以及重启恢复均不自动重发。已提交商品被拦截重复提交，必须先核对已有记录。
- 采集操作固定到所选 ERP 的浏览器与账号，运行时阻止修改连接及并发上架操作。停止批次会等当前商品得到结果后停止后续条目。
- 通过店小秘公开页面操作，不调用未公开的采集接口。当前执行器使用公开的产品数据文件导入页面，不依赖采集插件。
- 回读按来源URL精确搜索未认领记录并进入编辑页逐SKU校验。单独成功计数不作为入箱证据；找不到、重复或字段不一致时返回待核对。
- 采集属于平台字段转换，不能保证平台之间逐字节完全一致。业务上的“原封不动”指保留源链接、不主动二创或改写；完整性需要在真实样本中核对。
