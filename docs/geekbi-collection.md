# 极鲸云选品 → 店小秘采集箱（试运行）

入口为 `/sourcing`，导航名称“自动选品上架”。本阶段终点为店小秘通用采集箱的未认领记录。自动选择店铺、发布到 SHEIN、图片二创均未接入这个模块。

## 使用

1. 在新板块填写极鲸云 App Key 和 App Secret，保存并检查免费的站点列表。凭据复用 Windows DPAPI 加密存储，不在页面回显或进入 Git。
2. 选择站点，输入一个或多个关键词，或从免费类目列表选类目。可用已配置的文本模型整理自然语言需求，核对条件后手动查询。每个关键词只取第1页，不自动翻页；页面显示预计点数，实际费用以服务回执和控制台为准。
3. 选择现有店小秘 ERP 连接。其绑定浏览器中需要有效的登录账号，连接设置须填写账号显示名。首次仅提交1件，回读确认入箱后才开放每批20件。
4. 使用真实 Temu 商品详情链接采集，关闭自动认领，只点击“开始采集”。极鲸云 `linkUrl` 如果指向极鲸云自己的详情页，会先在 Temu 前端按商品ID找到可见的原始详情链接。
5. 遇到验证码、页面结构变化、账号不符、采集失败或不明确结果时停止后续条目。进入原浏览器处理；“只核对入箱结果”不会重发采集。可在已打开的商品页面使用官方店小秘插件完成采集，再核对同一个批次。

## 已取得的真实证据（2026-11-17）

- 登录后的极鲸云在线调试器用 `canvas wall art` 查询3件，HTTP 200、code=0。此步骤验证了账户查询能力，不等于工作台 HMAC 凭据已完成真实联调。
- 第一件商品ID `601105252678120` 的 `linkUrl` 指向极鲸云研究详情页。其“Temu链接”也是按ID搜索链接；从 Temu 搜索结果中另行读取了真实商品详情链接。
- 对该商品调用原始详情调试接口返回 HTTP 404“未找到商品原始详情”。本模块不依赖该50点接口，不自动重试。
- 浏览器前端沿用日本站，极鲸云返回的站点为美国站。搜索快照价格不能当作前端采集价格；页面明确提示地区差异。
- 真实店小秘链接采集试验：执行1件，成功0、失败1。页面显示“采集产品失败，建议使用插件采集，成功率更高”，同时提示未安装采集插件。尚无真实成功入箱证据，不能将模块描述为已经端到端跑通。

本地实测原始证据放在工作目录外的 `outputs/geekbi-integration-20261117/`，不随产品打包。安装官方插件、在本地表单保存凭据后，仍需完成工作台接口签名联调和单商品实际入箱验收。

## 实现边界

- 查询与批次状态保存在用户数据目录 `sourcing/`；保留供应商返回字段和接收时间，不让模型生成商品事实或改写图片、标题、规格。
- 请求编号幂等。付费查询超时、浏览器提交后断线以及重启恢复均不自动重发。已提交商品被拦截重复提交，必须先核对已有记录。
- 采集操作固定到所选 ERP 的浏览器与账号，运行时阻止修改连接及并发上架操作。停止批次会等当前商品得到结果后停止后续条目。
- 通过店小秘公开页面操作，不调用未公开的采集接口。当前执行器支持链接采集和可见页面回读；插件按钮流程未做自动点击联调，保留人工接管。
- 回读要求选中的“未认领”分类内有同商品原始链接、标题及图片。单独弹出成功计数不作为入箱证据。当前仅检查筛选后的当前结果页，找不到记录时保守返回待核对；不声称已验证每个SKU和图片完全无损。
- 采集属于平台字段转换，不能保证平台之间逐字节完全一致。业务上的“原封不动”指保留源链接、不主动二创或改写；完整性需要在真实样本中核对。

## 验证

`npm run check`、`npm test`、`node tests/browser-sourcing.mjs`、`node tests/browser-navigation.mjs`。

新增单元测试覆盖签名、原始链接识别、凭据不回显、查询幂等、失败停止、未知提交恢复和本地请求保护。浏览器测试使用独立数据与模拟接口，不消耗极鲸云点数，不写真实店小秘，不能代替真实入箱验收。
