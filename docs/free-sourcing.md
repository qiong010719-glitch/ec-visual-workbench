## SadCaptcha 自动验证

在免费选品页填写 SadCaptcha API Key 并保存。密钥复用 Windows 当前账户 DPAPI 加密存储，只显示“已配置”，不会注入 Temu 页面或写入任务记录、错误日志。点击“检查连接与余额”才访问供应商余额接口；页面轮询只读本地缓存，显示最近查询时间。

当前浏览器适配器支持已核验 DOM 结构的 **Temu 直线及弧形滑块**。弧形版本按官方要求逐像素采样轨迹。2026-11-21 实页观察到的直线版本采用随机节点ID，按可见背景、拼块及滑轨关系定位；按下后重新取图，并用一次短距离拖动校准实际位移率，兼容页面缩放。两种版本均保持鼠标按下等待识别结果，移动至返回位置后释放，再回读页面确认通过。只有返回本任务的关键词搜索列表或对应商品及可用采集按钮才记为通过；访问失败页、登录页或空白页不算成功。

同日详情页出现 `#Picture` / `#captchaImg` 的单点语义题“请点击距离火车最近的球”，已接入 `semantic-items`。仅对明确支持的文字规则做忠实英文转换，单点题只接受一个归一化坐标，按页面实际图片宽高计算点击位置，再核对原题并点击唯一提交按钮。未知语言规则、过期图片、多点答案或停止请求均不会继续提交。滑块与点选共用每批额度，其他布局仍需单独适配；接口宣称支持语义对象并不等于本题实测成功。

实测还遇到 `#imageSemantics` 九宫格顺序题，使用官方 `temu-three-by-three` 接口。请求按实际九张图的行列顺序传 `images`，将明确支持的物体名转换为英文 `objectsOfInterest`；按返回的 `solutionIndices` 逐个点击并提交。选中状态会额外插入标记图片，只读取每个角色容器的直接图片，避免把标记误当成第十格。题目、图片、数量或顺序无法确认时停止，不重发同图识别。

每批默认最多请求2次，可设0—30；0为手动。额度跨搜索页、商品页及恢复共用，不因刷新或重启重置。同图像不重复请求；超时、断流或未知结果保留记录并阻止自动重发。请求之前落盘意图，状态中断恢复为“结果待核对”。遇到不支持类型、拖动未生效、页面已变化或达到上限时保留页面和进度。停止任务会在下一次识别或提交前再检查停止标记。

“免费选品”指不调用极鲸云搜索和详情接口；SadCaptcha 识别仍按供应商账户规则计费。调用次数不是美元/人民币金额，也不承诺失败退款。实际余额和费用以供应商记录为准。

## 采集与恢复

- 录屏流程持久化为 `collectionMode: "recording"`。顶部绿色成功提示与底部插件状态均须属于本次点击；点击前已经存在且未变化的成功提示不能放行。成功回执先落盘为 `collected`，随后才切回原关键词搜索页；`collected` 表示插件已报告成功，不等于已确认入箱。最终只有采集箱回读成功才是 `verified`。
- 同一任务的账号检查、最终核对和“打开采集箱”复用持久化的 `tabs.collection` 专用标签。成功或重复提示落盘后返回搜索页，并关闭本任务创建、商品身份和回执目标均匹配的详情标签。正常连续采集保留一个搜索页、一个采集箱页及最多一个临时商品详情页；验证码、失败或身份变化时保留现场。旧版本未记录所有权的历史标签不按网址批量关闭，用户其他标签也不参与复用或清理。
- 常规采集不查询采集箱查重，也不因其他任务已有成功记录而提前跳过；重复由 Temu 前端店小秘提示决定。明确的重复提示保存为 `skipped-duplicate`，网页内提示直接离开本任务详情页；已核实的原生重复确认框仅取消，不确认再次采集。已有不明提交、历史重试和验证码次数保持不变；真正的提交失败、无回执超时、错误商品回执或返回搜索页失败仍保留现场。服务重启后先核对已提交记录，不重放点击。旧任务保留原逐件核验方式，可通过恢复参数显式切换至录屏流程。
- 检测到安全验证时优先按当前任务额度执行 SadCaptcha 适配流程；缺少密钥或无法确认通过时进入“验证待处理”。保存密钥或在原浏览器完成处理后点击“已处理，继续”。不反复刷新挑战页。
- Temu 返回 `/bgn_no_access.html`、“没有网络连接”等页面时单独显示“Temu访问失败”，不会当作滑块处理或发起收费请求。恢复访问后继续原任务，重用原标签页重新打开搜索。
- 页面刷新和服务重启后均保留关键词、候选商品、标签页编号、已提交时间、入箱证据、验证码调用记录和失败原因。
- 每次插件点击前先保存提交意图。普通继续和只读核对不重复点击。需要恢复中断的插件采集时，可明确指定已有提交重试一次；修复商品进入路径后可明确从真实搜索结果额外重开一次。每次点击前必须再次确认采集箱无记录，保留原始提交时间及重试历史，总共最多2次明确恢复。重启、同账号跨任务均不重置该限制。
- 已核对但仍未确认的提交可明确暂缓，继续原候选列表中的后续商品；待核对项不会计入成功。有效商品页明确显示“此商品已售罄。”、且没有商品标题及详情时，只记录该次详情页不可用，不认定真实库存为零，不点击推荐商品补数。2026-11-21 对照实测发现同一已采集商品直接打开URL显示售罄、从搜索结果原生点击则可显示完整详情；因此生产入口使用真实主列表链接。修复入口后可保留历史观察并重测这些未提交项。原列表未全部核实入箱时整批不会标记完成。
- 采集结束后的入箱核对，以及已有不明提交的明确恢复，在“来源URL”查询方式下使用 `decodeURI(sourceUrl)` 解码后的完整原始来源链接查询。实际页面按原始中文链接匹配；商品 ID 包含查询未获支持，不能将其空结果用于授权新采集。查询输入、分类及加载状态必须保持一致，新商品首次点击不依赖空箱结果；只有明确要求重试已有不明提交时，才需要对应完整链接的可见空结果。超时、旧表格和单纯找不到记录均不当作空箱。
- 回读表格中的实际来源链接，严格校验 HTTPS、Temu 域名和商品路径，并确认解析出的 `goodsId` 与请求商品相同。已有记录会复用并核对；同一行重复链接去重，不同记录对应同一商品时暂停核对。证据保存实际 `sourceUrl`、原请求 `requestedSourceUrl` 和 `matchBy: 'temu-goods-id'`。此兼容只适用于免费流程；XLSX 文件导入仍使用完整 URL 查询和精确来源链接匹配。
- 点击采集不等于成功：必须在绑定账号的未认领采集箱找到唯一同商品、含标题与已加载图片的记录。这里只验证记录存在，不声称记录由本次新建、完整SKU/媒体文件逐字节校验，也不自动认领、编辑或发布。
- 插件安装/登录缺失、按钮不唯一或遮挡、账号绑定改变、来源商品变化时暂停。若检测到插件可见的“自动认领”已开启，也会暂停；使用前应确认插件配置未开启自动认领。
- 运行中与原选品、上架和连接修改互斥。暂停后可进行其他工作；恢复前重新核对原账号/浏览器绑定。
