# 桌面端连接设置

更新：2026-11-24。入口为工作台左侧的“设置”，本地页面 `/settings`。

## 服务密钥

页面顶部提供生图、文字、视频、链接分析四个独立板块。生图与文字沿用算舟，视频密钥作为后续接入准备保存，链接抓取沿用已有 Apify 客户端。请在对应服务的网站获取密钥；服务地址、模型及调用方式由网站内置，页面不提供修改入口，保存接口也拒绝这些字段。已有安装配置保留，网站维护者仍可从部署配置维护服务。

四类密钥使用本机 Windows 账户加密保存，响应只返回是否配置，不返回密钥。留空保留原密钥；成功保存后清空输入框，失败时保留输入以便处理。密钥不进入浏览器表单恢复缓存。已保存不代表服务已验证可用；保存本身不调用供应商。视频生成尚未接入，不把视频密钥已保存显示成视频服务可用。

链接分析密钥保存后即时传递给现有研究采集服务，无需重启，也不自动创建采集或生成任务。

## 首次使用

1. 保留日常使用、已登录店小秘且装好采集插件的 Chrome。在正确的 Chrome 用户中保留店小秘页面，打开 `chrome://inspect/#remote-debugging` 并启用远程调试。无需关闭或重启 Chrome。
2. 在工作台点击“使用当前 Chrome”保存连接。填写 ERP 类型与账号显示名，选择该 Chrome 连接并点击“保存并打开登录”。Chrome 出现连接授权提示时选择 Allow（允许）。工作台会在同一用户配置中新开工作窗口，复用已有登录和插件；返回工作台点击“检查登录”核对账号。
3. 已有插件无需重新安装。进入免费选品页，确认接收账号绑定的是“复用当前 Chrome”，点击“检查插件”；插件已启用和账号登录分别核实。
4. 按业务选择入口：
   - 采集商品上架：进入固定上架模板，配置采集箱商品的填写规则及店铺，母稿不是此流程的前提。
   - 做图或成品图片上架：添加店铺和站点，粘贴该店商品编辑链接作为母稿，点击“校验并保存店铺”。也可先“读取并校验母稿”查看结果，母稿名称可留空。

服务密钥位于页面顶部，浏览器与 ERP 连接流程保留。极鲸云选品属于按需配置，入口放在页面下方。

## 将旧独立窗口切换为当前 Chrome

已有配置保留原连接方式，页面刷新不会自动切换。进入“连接 Chrome 浏览器”，在原连接旁点击“调整设置”，把连接方式改为“使用已打开的 Chrome（复用登录和插件）”，再点击“保存并应用”。绑定该连接的 ERP 登录与新采集任务使用当前 Chrome；旧独立窗口的数据目录保留。

如果另外新增了“当前 Chrome”连接，还需在 ERP 账号的“编辑”中将浏览器改为该连接并保存。只新增浏览器不会改变旧账号的绑定。历史任务保留建立时的绑定，不因切换连接自动迁移或继续；应先核对已有任务结果再创建新任务。

保存配置不要求 Chrome 已连接，也不会打开浏览器或请求授权。首次实际连接时才核对 Chrome 状态及授权；未启用或未允许时提示处理，不会改为启动独立浏览器。多个 Chrome 用户同时有业务页面时需先明确使用本次账号所在用户，避免选错插件和登录资料。

## 已有配置与状态

- 已有浏览器和 ERP 先显示摘要，编辑表单默认收起。复用当前 Chrome 无需填写端口或程序路径；独立窗口模式保留端口及程序路径设置。
- “配置已保存”只说明本机保存成功；“本次登录已核实”需要本次检查读到匹配的真实账号。刷新后重新显示待检查，未核实、账号不匹配或不支持登录检查都不显示成功。
- 打开登录失败时保留已保存的连接，使用账号行的“打开登录”重试，不重复创建账号。
- 修改浏览器、端口或账号会让相应登录检查失效。同一浏览器关联的账号在打开或检查登录时清除之前的检查证明。
- 执行配置操作期间禁用交互，阻止重复提交。后端仍保留配置版本冲突、账号绑定、母稿校验以及业务任务占用检查。

## 输入恢复与删除

浏览器、ERP和店铺表单可恢复当前本地输入。店铺编辑收起后可点“继续未保存的填写”；修改其他连接不会悄悄改变草稿选择的 ERP。原连接被删除时选择留空，要求重新选择。已保存店铺的新增或变更继续通过后端母稿验证，不因界面简化而跳过。

删除入口放在“更多”中，点击前确认。关联关系仍由服务端检查；不能直接删除还被店铺使用的连接。页面不会自动探测或导入 ERP 店铺列表，也不声称按平台唯一店铺 ID 完成绑定。

## 验证范围

- `node --test tests/merchant.test.mjs tests/settings.test.mjs`：配置持久化、关联关系、密钥存储与既有商家流程。
- `node tests/browser-service-keys.mjs`：四类密钥保存、留空保留、失败恢复、刷新不回显、内置配置拒绝修改、链接抓取即时配置，以及深浅色与窄屏布局；无供应商调用。
- `node tests/browser-template-settings.mjs`：母稿长 ID、当前输入、增删行保留、刷新回读、无效链接不覆盖。
- `node tests/browser-connection-settings.mjs`：首次连接、重复提交、检查状态、失败恢复、多账号、端口变更、表单恢复、390/1024/1440宽度。
- `node tests/browser-existing-chrome.mjs`：复用模式、旧连接兼容、ERP 绑定和未授权时不回退到独立窗口。
- `node tests/browser-plugin-setup.mjs`：按当前账号显示浏览器模式、插件检查和设置入口使用正确连接、检查不自动采集。
- `node tools/check-source.mjs`：页面脚本语法和静态引用。

浏览器回归使用独立临时数据、模拟 ERP 适配器并拦截外部请求；未操作真实店小秘商品，也不替代采集到发布的真实业务验收。
