# 淘宝对标链接接入与验收

日期：2026-11-14。基于 PR #7 的 `ec70a0972f479e2143f501ce973c6bad2d5779f1`，新分支 `codex/taobao-benchmark-links`；保持 draft，不合并 main。

## 页面操作

工作台的淘宝张数、尺寸设置下方新增「对标链接与版式参考」折叠区。

1. 填写本品名称、真实卖点，上传自己的主体图和对应 SKU 图；设置本次主图、SKU、详情张数与画幅。
2. 粘贴一个淘宝／天猫完整商品链接，或含 `e.tb.cn`、`m.tb.cn` 链接的分享文案。点击「Apify 读取链接图片」后才会请求抓取服务。每次一个商品、不抓评论，费用上限0.05美元；完成后显示Apify记录的抓取费用。
3. 查看按来源分组的主图、SKU、详情原图，为需要参考的输出逐张选择同类图片。默认不自动绑定；缺失的详情不会用主图补成详情。
4. 点击「分析并用于构思」。只分析选中的不同参考图，发送真实图片字节，提取背景、配色、文字层级、主体位置与阅读顺序；分析不启动生图。
5. 继续本站的「一键构思」，审看并修改逐图方案，再点击原有生成按钮。成图旁显示这张实际使用的版式参考，可打开查看；单图和 ZIP 仍下载原文件。

每张绑定图送入图片模型时，前面是本品身份图，最后一张是这张输出的对标图。SKU 继续使用既有逐槽 SKU 参考逻辑。本品身份图最多 7 张，为对应对标保留 1 张；没有本品图时在提交生成前报错。

没有绑定的图片沿用现有构思。改变绑定后需要重新构思；修改逐张要求、关闭或清除对标会保留本品素材和已有成图。改变输出张数导致槽位分类变化时，旧分类绑定不迁移到新分类。

## 接入边界

- 第一版支持淘宝／天猫，不宣称源项目支持的其他平台都已接入本网站。
- 主图、SKU、详情仍使用本站的数量、画幅、整套风格、逐张要求和图片模型。第一张主图没有重新加上白底要求；文字拖动没有恢复。
- 对标图用于布局和表达，本品图和已知事实决定商品、颜色、结构、SKU及文案。提示词明确排除竞品品牌、价格、参数、销量、认证和营销承诺；这不是模型永不出错的保证。
- 不新增发布、自动上架、视频、规格填报、自动多轮修图功能。没有修改 Temu 或裂变项目，也不调用源项目的服务。
- 接入开发后，用户明确授权付费实测、提供了对标链接，并在门禁确认问题后回复「你去做就好了」。按其最新指示执行本地三图试跑；不推断存在独立法律审查结论，不自动对外发布或合并。

## 服务、数据与重复请求

- 抓取使用 Apify `zen-studio/taobao-detail-scraper`。输入 `items:[商品编号]`、`fetchReviews:false`，运行设置 `maxItems:1`、`maxTotalChargeUsd:0.05`、`restartOnError:false`。同一任务只提交一次；不会自动回退万邦或其他供应商。
- 凭据复用服务进程的 `APIFY_API_TOKEN` 或 `APIFY_TOKEN` 环境变量，不复制到项目文件、网页、提示词或任务记录。本次复用已存在的用户环境变量，无需新增密钥文件。
- 视觉分析沿用本站 `VISION_*`，缺省回退到 `PLANNER_*`；状态显示「已配置」只表示配置存在，不证明在线接口可用或模型支持图片。图片生成提供商与型号未改变。
- 新接口为 `/api/taobao/benchmarks` 与 `/api/taobao/benchmark-analyses` 的提交、状态查询；沿用本机会话保护。读取状态只发 GET，不重新提交。`POST /api/taobao/benchmarks/resume` 对应「同步已有抓取」：仅使用已保存的运行编号查询原任务，不启动新的 Apify 运行。
- 每次点击先保存请求编号，再提交。重复编号返回同一任务；相同链接正在读取、同一资料正在分析时拒绝重复提交。超时、响应未知、重启后都不自动重发模型或抓取请求。
- 图片保存在 `data/media/`，资料和版式结果保存在 `data/taobao-benchmarks/benchmarks.json`，包含来源链接、分组、顺序、本地地址、SHA-256、时间、任务状态，以及Apify运行/数据集编号和已记录费用。先保存提交标记再下单；结果未知且没有运行编号时阻止同商品的新请求，需先核对控制台。
- 已成功的同商品资料可以复用；使用缓存前检查原图文件与哈希。文件丢失或变化时，用户主动再次读取会重新抓取。部分图片或分析失败时保留已成功结果；下一次明确的分析操作只处理尚未分析的选择。
- 不向本品素材库加入对标图片。服务器忽略客户端自填的版式和内部路径，只接受已保存、已分析的绑定编号；生成前再次核对文件哈希，并保存实际参考图顺序与角色。
