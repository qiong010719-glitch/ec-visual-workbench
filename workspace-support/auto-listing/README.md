## 运行只读检查

保留「店小秘-上架测试」比特窗口及目标草稿编辑页，使用 Node.js 22 或以上版本运行：

```powershell
node 'D:\agent合集\自动上架\scripts\inspect-draft.mjs'
```

脚本校验指定窗口、草稿、店铺和站点，再读取页面表单。它不输入、不保存、不发布商品，不读取登录凭据，不创建或关闭浏览器窗口。它只会在本地更新 `outputs/draft-inspection.json`。该文件反映读取时的编辑页状态，不单独证明服务端持久化成功。

## 这次验证得到的操作流程

1. 在独立标签页打开原稿，使用“存为模板”保存测试母版。
2. 打开创建产品，先选择店铺1和加拿大站，再通过“引用产品 → 引用产品模板”选择母版。
3. 模板不会完整复制标题、轮播图和变种，需要分别填写。通过“选择图片 → 网络图片”复用母稿三张图片；添加原稿的风格变种，并填入测试 SKU。
4. 选择加拿大仓库，带入原稿测试库存和数值，选择店小秘的“帆布画”分类。
5. SKU 预览图保持母稿中对应 SKU 的原图。新稿缺图时，以母稿独立 SKU 图片地址补入，不能取新主图替代。`setPreservedSkuPreview` 对已有不同图片报错，不静默覆盖。
6. 详情图使用与主图完全相同的图片和顺序。空详情通过“编辑描述 → 批量操作 → 批量传图 → 引用产品轮播图”补齐，逐张选择并等待状态更新，确认后保存描述。`fillEmptyDescriptionFromMainImages` 封装该流程，遇到已有不同详情内容先停止。
7. 只点“保存”；新建提示保存到待发布，编辑已有草稿提示“您的产品编辑成功”。点击继续编辑或重新读取，确认服务端持久化。
8. 从待发布列表确认新 SKU 只出现一次；重新加载原稿、新稿，等待类目、属性和 SKU 全部加载，再比较字段和三类图片。

草稿创建阶段由 Codex 的逐步脚本完成；目前尚未将整段模板引用、图片和变种填写封装成一个无人值守创建命令。新图片单稿测试已完成，接下来可整理创建流程和小批量处理。新增 UI 辅助函数按本次实际操作整理，尚未另建商品验证完整无人值守创建。
